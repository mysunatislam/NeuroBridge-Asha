# Asha 2.3 — Happy Female Avatar + Female Voice

## What changed
- Asha now has a clearly feminine, cheerful avatar with a ponytail, eyelashes, blush, earrings, brighter colors, and a broad default smile.
- The compact floating Asha button now uses the same happy female visual identity.
- Asha defaults to **Bright Female** voice and also offers **Gentle Female** and **Natural Female** profiles.
- Speech synthesis now prioritizes known female English and Bangla system voices when available (including common Nabanita/Tanishaa and English female voice names).
- A friendly pitch profile is applied while preserving Slow / Normal / Fast speaking speed controls.
- Mood states (Smile, Sad, Pain, Okay) still alter Asha’s expression without changing the default friendly personality.

## Browser note
Web Speech API voice inventories differ by operating system and browser. The app strongly prioritizes female voices, but the exact installed voice is controlled by the user’s device.
