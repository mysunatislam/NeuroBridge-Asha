# Original prototype provenance

`files.zip`, `fingerspeak.html`, and `README.md` are the unchanged source materials supplied for the
migration. They are retained for comparison only. The legacy HTML loads executable camera-page
dependencies from third-party CDNs, uses a non-standard `window.storage` API, accepts insufficiently
validated profile JSON, and does not stop camera tracks explicitly. Use `apps/web` for the upgraded
application.
